# GPU66 physical audit execution

Two fresh assigned regular audits are accounted for independently from Native
request-authorization receipts. A calculation already shown as a previous
cycle's catch-up cannot also fill a new physical regular slot. At most one
catch-up starts per new cycle; partition scans and restart never spend another
allowance. Prior admitted legacy work is preserved. A confirmed empty eligible
pool can waive only the additional physical slot at its authenticated Core
availability anchor; Native request authorization is never waived by this host.

Completion identities are retained across attachment/restart for newer GUIs.
The hot execution metadata is bounded to active cycles, independently of the
archived work journal. No answer, commitment, signature, reward or Native
consensus rule is fabricated or changed. Historical answers still require
their holder's publication. Scientific kernels and the public UI128/Core13/
CPU389 remain unchanged in this component-only delivery.
