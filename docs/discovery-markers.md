# Discovery markers

Best and Recent show a small rosette to the right of noteworthy gap lengths.
Rust, bronze, silver and gold use the exact original ticket target. A missing
target does not imply an award tier. These markers identify discoveries and
potential reward claims; wallet credits are shown separately after validation
and inclusion in the chain.

A green/gold record rosette and the existing star require the independent
certificate-gated comparison with the loaded prime-gap reference. An
improvement against that reference is not a claim that a public record has
already been accepted. Reloading a reference can retract its eligibility.

Ticket audit evidence remains in its dedicated range/flow indication. A merit
color, discovery rosette or reference star does not certify a network payment.

The renderer caches a bounded set of icons at three pixel densities. Selection
keeps the category colors; progress-only updates preserve the existing model
items and selection. The same renderer and classification serve both tables.
